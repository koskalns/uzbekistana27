# Kartes dati un izcelsme

- Valstu kontūras: [Natural Earth, 1:110m Admin 0 Countries](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson). Iegūtas 2026-10-17. [Publiskais domēns](https://www.naturalearthdata.com/about/terms-of-use/). Saglabāti Centrālāzijai nepieciešamie objekti; SVG izmanto vienādstūru projekciju ar koordinātu novietojumu, nevis ilustratīvi izvietotus punktus. Mērogs ir paredzēts valsts pārskatam, nevis navigācijai.
- Beldersay apdzīvotā vieta: [OpenStreetMap way 224624989](https://www.openstreetmap.org/way/224624989). `beldersay-source.json` saglabā avota objektu un mezglus. Marķieris ir apdzīvotās vietas daudzstūra mezglu vidējā koordināta, nevis takas vai nometnes sākums.
- Čimganas ciems: [OpenStreetMap way 224137716](https://www.openstreetmap.org/way/224137716), orientieris 41.56228 N, 70.02393 E.
- Taškenta: pilsētas orientieris 41.3111 N, 69.2797 E. [Vieta OpenStreetMap](https://www.openstreetmap.org/#map=13/41.3111/69.2797).
- Lielais Čimgans: 41.495 N, 70.05778 E, [Wikimedia Commons foto apraksta virsotnes koordinātas](https://commons.wikimedia.org/wiki/File:Kumbel_to_Chimgan.JPG). Netiek izmantota fotogrāfa Kumbel stacijas koordināta un netiek apgalvots, ka maršruts sasniedz virsotni.
- OpenStreetMap dati: © OpenStreetMap contributors, [ODbL](https://www.openstreetmap.org/copyright). Redzamās pamata kartes flīzes tiek ielādētas no `https://tile.openstreetmap.org/{z}/{x}/{y}.png`, ievērojot [flīžu lietošanas noteikumus](https://operations.osmfoundation.org/policies/tiles/). Nav flīžu priekšielādes vai bezsaistes lejupielādes funkcijas.
- Leaflet 1.9.4: vietēja bibliotēkas kopija `assets/vendor/leaflet/`, BSD-2-Clause licence saglabāta kopā ar kodu. [Oficiālā izplatīšana](https://leafletjs.com/download.html).

Kartes aplis ir redakcionāli izvēlēts apvidus pārskats (6,5 km rādiuss pie Čimganas/Beldersay), nevis administratīvā robeža vai apstiprināts pārgājiena koridors. Precīzie Nurekata–Kumbel–Aksakata/Gidjal posmi un nometnes nav verificēti, tāpēc tie nav uzzīmēti kā taka.
